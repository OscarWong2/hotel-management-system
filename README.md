# Hotel Management System

A Java application that allows for managing a hotel's bookings, room assignments, customers, and employees using a MySQL database.

## Concepts

- Object-Oriented Programming
- Graphical User Interface
- Database Integration

## Functionality

- Check customers in or out
- Create, reschedule, or cancel bookings
- Assign rooms upon check-in
- Search and filter hotel records
- Automatically calculate booking charges and manage customer loyalty points
- Automatically update booking statuses based on check-in and check-out times
- Employee authentication

## Built Using

- MySQL
- Java Swing
- JDBC

## Important Notes

- The application requires a MySQL database connection to access and manage hotel records.
- The background and window icon images originally used by the application are not included in this repository for copyright purposes.
